## 📖 Descripción del Proyecto
Ude@Book es la capa lógica de una red social desarrollada en C++ puro, aplicando los principios de la Programación Orientada a Objetos (POO). El sistema gestiona un volumen de **1000 usuarios**, administrando perfiles, relaciones de amistad, mensajería bidireccional y álbumes fotográficos con carrusel.

### Restricciones cumplidas
- ❌ Cero uso de la STL.
- ❌ Cero uso de `struct`.
- ❌ Cero uso de ANSI C.
- ✅ Gestión manual de memoria (`new` y `delete`).
- ✅ Plantillas propias (`template <typename T>`).
- ✅ Diseño modular (`.h` y `.cpp`).
